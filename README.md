Проект "Таймер для заваривания чая"

После включения устройство предлагает задать время задержки отсчета в интервале 0 - 9 сек. По дефолту значение 3.
Эта задержка задумана как время, необходимое на то чтобы залить воду в гайвань/чайник и накрыть крышкой.
Далее выставляется время для заваривания чая - минуты(0 - 99), затем секунды(0 - 59), и можно запускать.
Сперва отсчитывает задержку, затем основное время. Эти значения сохраняются и на следующем круге будут стартовыми.
Удобно если предыдущий пролив был 40 сек, а текущий надо сделать 50 - тогда не надо крутить секунды начиная с 0.
Если задержка 0, то работает как простой таймер.
По истечении времени издаст 30 звуковых сигналов и пойдет на новый круг с установки задержки.
Управление поворотами энкодера для смены значений времени, нажатие для подтверждения и перехода далее.
Отмены нету. Долгое нажатие ничего не дает.
